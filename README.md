##Sistema de Restaurantes

Este projeto foi desenvolvido como minha **primeira aplicação em Python**, com o objetivo de praticar e melhorar meus conhecimentos na linguagem.
_____________________
## Sobre o projeto

O sistema funciona no terminal e permite gerenciar restaurantes de forma simples. É possível cadastrar novos restaurantes, listar os existentes e alterar o estado (ativado ou desativado).
___________________
## Funcionalidades

* Cadastrar restaurantes
* Listar restaurantes
* Alternar estado (ativado/desativado)
* Sair do sistema
______________________
## Linguagem:

* Python
_______________________
## Como executar

1. Baixe o projeto
2. Abra a pasta
3. Abra o terminal dentro da pasta
4. Digite:
python nome_do_arquivo.py
